# KrishiSeva

This repository is organized as a two-application workspace:

- `frontend/` contains the customer-facing TanStack Start application.
- `backend/` contains the backend application and its Supabase configuration.

Each application retains its own `package.json`, lockfile, environment configuration, and development scripts.

## Development

Install and run either application from its directory:

```sh
cd frontend
bun install
bun run dev
```

```sh
cd backend
bun install
bun run dev
```
